# الربط التجريبي مع Capital.com

هذا اختيار تقني لتجربة API على حساب افتراضي. لا يمثل توصية بإيداع أموال،
ولا إثبات ترخيص سعودي أو قبول حساب حقيقي. تحدد جهة الوساطة قبول الحساب
والكيان المتعاقد معه بعد التسجيل.

الموصل `capital_demo.py` يستخدم حصريًا:
`https://demo-api-capital.backend-capital.com`.
وظيفته تسجيل جلسة API وقراءة الحساب وتسعير الذهب. لا يرسل أوامر تداول.
الموقع المنشور ما زال غير متصل بوسيط؛ وجود الموصل وحده لا يفعّل الاتصال.

يلزم إنشاء حساب تجريبي من الموقع الرسمي وتوليد بيانات API. ضع القيم في
إعدادات Secrets الخاصة بالخادم؛ لا تدخلها في صفحات المحاكاة، أو GitHub،
أو في المحادثة. أسماء المتغيرات:

- `CAPITAL_DEMO_API_KEY`
- `CAPITAL_DEMO_IDENTIFIER`
- `CAPITAL_DEMO_API_PASSWORD`: كلمة المرور الخاصة بمفتاح API وفق إعدادات الوسيط.

بحسب الوثائق الرسمية، مفاتيح API لا تتوفر بصلاحية قراءة فقط؛ الموصل نفسه
يقتصر على القراءة والحساب التجريبي. لا تستخدم فيه بيانات حساب حقيقي.
لا يسجل الموصل قيم الأسرار أو نصوص استجابات المصادقة في الأخطاء.

المصدر الرسمي: https://open-api.capital.com/

فتح الحساب والموافقة على شروطه والتحقق من الهوية، إن طلبه الوسيط، يجب أن
ينفذها صاحب الحساب. لا يحول الموصل المحاكاة إلى تداول حقيقي تلقائيًا.
