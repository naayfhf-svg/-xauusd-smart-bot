# تجربة MT5 المحلية — قراءة فقط

هذه إضافة تشخيصية، وليست ربط تنفيذ آلي أو بديلاً كاملاً لمصادر التحليل.
لا تتصل النسخة المنشورة على Streamlit Cloud ببرنامج MT5 على الآيفون.
لا تتضمن هذه الإضافة خدمة شبكة أو منفذ استقبال أو أوامر بيع/شراء.

## المتطلبات
- ويندوز 64-bit عليه Python 3.12 وبرنامج MT5 من الوسيط.
- حساب XM تجريبي مستقل. حسابك الموجود ليس بالضرورة تجريبياً.
- تسجيل الدخول داخل MT5 يدوياً، وإضافة رمز GOLD الصحيح إلى قائمة الأسعار.
- تطابق currency_base=XAU وcurrency_profit=USD في مواصفات الرمز.
- تحميل 120 شمعة مغلقة على الأقل بإطار خمس دقائق.

## تشغيل نسخة الاختبار على ويندوز
من مجلد المستودع وعلى فرع هذا التعديل:
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt -r requirements-mt5.txt
$env:MT5_READ_ONLY_ENABLED = "true"
$env:MT5_EXPECTED_LOGIN = "رقم حسابك التجريبي"
$env:MT5_EXPECTED_SERVER = "الخادم التجريبي كما يظهر لدى XM"
$env:MT5_GOLD_SYMBOL = "GOLD"
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```
لا تستخدم رقم الحساب الحقيقي الموجود في محادثتك. لا ترسل كلمة المرور لأحد ولا تضعها في المستودع.
الموصل يستخدم جلسة MT5 المفتوحة، ولا يحفظ كلمة مرور أو يغير الحساب.

افتح قسم «اختبار ربط XM / MT5» في أسفل الصفحة واضغط الفحص.
النتيجة لقطة عند الطلب فقط، وليست بثاً مستمراً أو إشارة دخول.
السعر المتأخر أكثر من خمس ثوانٍ، والتوقيت المستقبلي، والحساب الحقيقي، وانقطاع الاتصال تُرفض.
لا نفترض فتح السوق لمجرد وجود آخر سعر؛ لا توجد صلاحية تنفيذ في هذه الإضافة.

## الآيفون
عند استخدام ويندوز سحابي، افتح جلسة سطح مكتبه عبر وسيلة وصول آمنة يوفرها المضيف.
افتح صفحة الاختبار في متصفح ويندوز نفسه داخل الجلسة. لا تفتح منفذ Streamlit للإنترنت.
لا يلزم شراء خادم قبل مراجعة نجاح اختبارات الكود وتحديد طريقة الوصول الآمنة.

## التحقق
اختبارات tests/test_mt5_readonly.py تستخدم MT5 وهمياً ولا تتصل بحساب.
شغّل pytest -q بعد تثبيت المتطلبات. نجاح CI لا يثبت نجاح اتصال XM الفعلي.
اختبر على ويندوز: الاتصال، فصل الشبكة، تبديل الحساب، وإغلاق MT5. يجب ألا تظهر نتيجة نجاح جديدة عند الفشل.
قراءة أسعار الوسيط لا تثبت ربحية أي استراتيجية.

## ما تبقى
إدخال الأسعار والشموع في مسار التحليل الأساسي، وربط الوصول البعيد بصورة آمنة، واختبار ويندوز/XM الفعلي.
لا تدمج تلقائياً. لا تفعّل تداولاً حقيقياً.
