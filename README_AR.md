# تحديث 6.1.4 — مراجعة عقود Call وPut

قسم «خيارات سهم» مستقل عن العقود الآجلة. يحلل الأصل على 5 و15 و60 دقيقة ويعرض شروط الاتجاه والزخم واختراق/إعادة اختبار. تتحدث مراجعة الأصل كل 60 ثانية ما دامت صفحة الخيارات مفتوحة، باستخدام مفتاح Twelve Data الموجود وضمن حدود المصدر. الرموز غير المدعومة والبيانات القديمة تؤدي إلى الانتظار.

أسعار الخيار Bid/Ask ما زالت تُدخل يدويًا من سهم. لا يوجد اتصال بحساب سهم ولا تنفيذ أو إشعارات خارج الجلسة. يحجب المحرك ترشيح المراجعة عند قدم سعر العقد بأكثر من دقيقتين، أو قرب الانتهاء خلال يومين، أو فرق أسعار أعلى من 10%، أو عدم اتفاق اتجاه الأصل، أو تجاوز تكلفة الشراء كاملة للميزانية، أو عائد الهدف الثاني إلى مسافة الوقف أقل من 1.5. هذه حدود تصميم للمحرك وليست نتائج استراتيجية مثبتة أو احتمالات نجاح.

المتابعة بعد تسجيل الشراء تعرض مراجعة الوقف والأهداف والانعكاس والانتهاء، والربح/الخسارة التقديرية بسعر Bid قبل الرسوم. لا تُحجب مراجعة الوقف بسبب ضعف اتجاه الأصل أو اتساع فرق الأسعار. تعادل الأصل عند الانتهاء محسوب قبل الرسوم، وليس توقعًا لسعر العقد قبل الانتهاء. سجل المراجعات قابل للتنزيل مع الخطة؛ الحفظ في الجلسة الحالية فقط.

لا توجد تغذية متصلة لسلسلة العقود أو IV أو Greeks أو أخبار الأرباح؛ اكتمال الشروط الفنية ليس إثباتًا لجودة العقد أو دعوة للشراء. لا يُقدّر سعر العقد من سعر السهم. مرجع تعليمي: https://www.optionseducation.org/advancedconcepts/volatility-the-greeks

التحقق المحلي: 54 اختبارًا للمنطق والواجهات، باستخدام بيانات اختبار. لم تُختبر ربحية الاستراتيجية أو اتصال حي بأسعار الخيارات أو التنفيذ لدى سهم.

# GOLD AI — 6.1.1 Stock Stability

تحديث مبني على آخر ملف محفوظ 6.1.0، مع فتح قسم الأسهم افتراضيًا والمحافظة على الذهب والعقود والبحث الموجود.

## التشغيل

يتطلب Python 3.12. من داخل مجلد المشروع:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

أضف مفتاح Twelve Data الحقيقي في `.streamlit/secrets.toml` باستخدام المثال المرفق، أو في Secrets باستضافة Streamlit. لا تنشر المفتاح في GitHub. لم يتم تضمين أي مفاتيح أو حسابات في هذا الإصدار.

لتحديث نشر Streamlit الحالي: استبدل app.py وrequirements.txt بملفي هذا الإصدار ثم أعد التشغيل. هذه الحزمة لم تُرفع إلى مستودعك أو نشرِك الحالي تلقائيًا.

## ما تم إصلاحه

- حساب الإغلاق اليدوي بعد جني نصف المركز يراعي الجزء المحقق والمتبقي، وحماية الإغلاق من الاحتساب مرتين.
- وقف الخسارة التجريبي يحتسب فجوة السعر عند السعر المرصود بدل افتراض التنفيذ المثالي عند الوقف.
- حساب الهدف الجزئي حسب مستوى الهدف الفعلي.
- تطبيق حدود الخسارة التكيفية والخسائر المتتالية داخل التحديث التلقائي أيضًا، وتجديد عدادات اليوم أثناء عمله.
- حفظ حالة المحفظة ومفتاح منع التكرار في معاملة واحدة، مع منع الجلسات القديمة من الكتابة فوق الحالة الأحدث.
- إيقاف فتح صفقات عند فشل الحفظ واسترجاع آخر حالة سليمة، بدل تجاهل فشل الحفظ.
- رفض المدخلات غير المحدودة والأسعار غير الموجبة والعرض/الطلب المعكوس والتوقيت المستقبلي غير المقبول والشموع غير الصالحة.
- منع فتح صفقات تلقائية خارج وضع Paper.

## حدود الجاهزية

هذا إصدار مُختبَر للتطبيق والمحاكاة، وليس ربطًا مكتملًا بوسيط. IBKR غير مربوط فعليًا، وLive للأسهم محجوب كما في النسخة السابقة. لا توجد أوامر حقيقية أو أموال فعلية ضمن الاختبارات. يلزم استكمال اتصال الوسيط والتحقق منه على حساب Paper قبل وصف ذلك الجزء بالجاهز.

الاختبارات تستخدم بيانات سوق اصطناعية معزولة داخل الاختبارات فقط. لم يُختبر اتصال Twelve Data بمفتاحك أو اشتراكك، ولم يُختبر نشر Streamlit الخاص بك. نجاح الاختبارات لا يضمن انعدام كل خطأ أو ربحية الاستراتيجية.

قاعدة SQLite محفظة واحدة مشتركة لمالك التطبيق؛ استخدم نشرًا خاصًا. المسار الافتراضي /tmp غير مضمون عند إعادة بناء الاستضافة. اضبط GOLD_AI_STATE_DB_PATH على قرص دائم للاحتفاظ بالبيانات بعد إعادة النشر، واحتفظ بنسخة احتياطية من القاعدة. لم نُرحّل بيانات صفقاتك لعدم توفر قاعدة بيانات نشرِك.

التحديث التلقائي مرتبط بجلسة المتصفح، وليس عاملًا يعمل 24 ساعة بعد إغلاقها. المحاكاة تبسط التعبئة والسيولة والعمولات والتسوية؛ لا تمثل محاسبة حساب Cash حقيقي. تصحيح الحسابات ينطبق على الصفقات اللاحقة، ولا يعيد احتساب سجل قديم تلقائيًا.
